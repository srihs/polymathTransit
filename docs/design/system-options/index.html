PolymathTransit: five design directions

For the owner's choice of system theme · Prepared 01/10/2026 · Draft

How to compare them

Each direction uses the same brand colour (the crest purple), the same content and the same four pages, so you compare design, not content. Open each direction's request form and driver page on a phone, or narrow your browser to about 360 px wide; open the dashboard on a computer.

This gallery is plain on purpose and favours none of them. The order is by number only. The research behind the directions is in research.md, and the brief the five were built from is in brief.md. All Sinhala text is a draft that native speakers still need to review.
